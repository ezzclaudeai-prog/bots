# bots

## bot_v4_supreme_slider.js

نسخة V4 (سلسلة QUANTUM) + محرك **TickForecast** (V26) — الإسقاط الاحتمالي الأمامي.

### الفكرة (طلب المستخدم)
بدل «اتجاه عشوائي» أو زخم خام يخسر 50–60% من الصفقات، يعقد البوت الآن **عملية حسابية
دقيقة على التيكات الخام** قبل كل دخول، ويعرض النتيجة في الـHUD وفي السجل.

### ماذا يحسب TickForecast (من التيكات الخام، بتوقيت الخادم)
| القيمة | المعنى |
|--------|--------|
| `cadence` | وسيط الفاصل بين التيكات → متى يصل التيك القادم (≈470–500ms للـOTC) |
| `drift` | ميل العائد اللوغاريتمي المُشذّب لكل تيك (وسيط ∩ متوسط، مقاوم للقفزات) |
| `sigma` | تذبذب العائد لكل تيك |
| `pWin` | احتمال الفوز = CDF طبيعي لمشي عشوائي بانجراف على الأفق |
| `EV` | `pWin·payout − (1−pWin)` |
| `bestHorizon` | المدة التي تُعظّم `pWin` بين مدد المنصة `[10,15,20,30,45,60]` |

النموذج: العائد التراكمي على N تيك ~ `Normal(N·drift, sd²)` حيث
`sd = σ·√(N + N²/n)`. الحدّ `N²/n` هو **عدم يقين تقدير الانجراف نفسه** — بدونه
يظنّ البوت أن انجرافاً بمستوى الضجيج «حافة مؤكّدة» فيبالغ في الثقة على سوق هادئ.
بوجوده يصبح `pWin` محدوداً بدلالة الانجراف الإحصائية (t‑stat)، فلا يصل أبداً إلى 100%
من ضجيج، وعلى سوق هادئ يقترب من 0.50 → **بوابة EV ترفض الدخول العشوائي**.

### البوابات والربط
- **بوابة EV** (`FC_GATE_BLOCK`): ترفض الدخول السالب القيمة إحصائياً في مساري
  `tickPulse` المباشر و`_processSignal` الموحّد. إشارة الفاصل `interval_signal`
  تبقى استشارية (لا تُحجب).
- **أفضل مدة** (`FC_DURATION_ENABLED`): تستبدل المدة الثابتة بالمدة المحسوبة.
- **مراقب صحة الصفقة** (`FC_HEALTH_ENABLED`): يعيد حساب `pWin` كل تيك أثناء الصفقة
  ويعرضه في خانة «التوقّع» بالـHUD مع تحذير عند هبوطه تحت `FC_HEALTH_DANGER`.
  ⚠️ المنصّة لا تتيح إغلاقاً مبكراً للخيارات الثنائية، لذا «تجنّب الخسارة» يتحقق
  عبر **انتقاء الدخول والمدة** (بوابة EV) لا عبر خروج لحظي — المراقب استشاري وبيانات تعلّم.

### ملاحظة صادقة
على فريم 5ث في أزواج OTC، معظم النوافذ انجرافها ≈ 0 (السعر بالكاد يتحرك بين تيك وتيك)،
فالبوابة سترفض أغلب الإشارات وتتداول **أقل بكثير** — وهذا هو المقصود: لا صفقات على
رمي العملة. الحافة الحقيقية تظهر حين يوجد انجراف معنوي (t‑stat واضح) أو على فريمات أطول.

### الإعدادات (CFG، بادئة `FC_`)
`FC_ENABLED, FC_GATE_ENABLED, FC_GATE_BLOCK, FC_DURATION_ENABLED, FC_HEALTH_ENABLED,
FC_WINDOW_MS, FC_MIN_TICKS, FC_PAYOUT, FC_EDGE_BUFFER_REL, FC_EV_MIN, FC_PWIN_MIN,
FC_HORIZONS, FC_HEALTH_DANGER`. للوضع الاستشاري فقط (بلا حجب): اجعل `FC_GATE_BLOCK=false`.

### إصلاح إضافي
كشف الفريم الديناميكي: `candlePeriod` كان يُلتقط مرة واحدة فقط؛ الآن يتحدّث عند تغيّر
الفريم (history) بعد قفل 30ث مع إعادة بناء شموع الزوج.

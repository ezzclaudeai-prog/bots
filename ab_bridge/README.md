# A/B Latency Bridge — reference scaffold  [TASK-2]

> **اقرأ هذا أولاً.** هذا الجسر يعمل **فقط** على أصل **حقيقي** له **مصدر سعر مرجعي
> مستقل يقود الوسيط** (مثل EUR/USD، الذهب، BTC). **لا يعمل على أزواج OTC في
> Pocket Option** لأنها مُولَّدة داخلياً من خادم واحد — لا يوجد «مصدر أسرع» تسبقه،
> وسعر التسوية يأتي من نفس الخادم لحظياً (راجع نقاش كرة القدم).

## متى يربح latency arbitrage؟ (شرط كرة القدم)

تربح فقط إذا اجتمع الآتي:

1. **مصدران لنفس الأصل بتأخير مختلف:**
   - `A` = مصدر مرجعي **سريع** يقود (مزوّد سوق حقيقي).
   - `B` = فيد الوسيط الذي **ستراهن عليه** (المتأخر).
2. **الرهان يُقبل على `B` (المتأخر)** بسعره المتأخر — هذا هو المفتاح.
3. الوسيط `B` يسعّر الأصل من **نفس المُحرّك** الذي يقوده `A` (بتأخير شبكي/معالجة).

عندها: عندما يتحرك `A` الآن، تعرف أن `B` **سيتحرك بعد لحظات** → تدخل على `B` قبل أن يلحق.
هذا **ماضٍ مؤكَّد بالنسبة لـ A، مستقبلٌ بالنسبة لـ B** — تماماً كالهدف في البث المتأخر.

## لماذا لا ينطبق على PO-OTC (باختصار)

| الشرط | كرة القدم | PO OTC |
|---|---|---|
| مصدران بتأخير مختلف لنفس الأصل | ✅ | ❌ خادم واحد |
| الرهان على المصدر المتأخر | ✅ | ❌ تراهن على نفس الخادم الأحدث |
| سعر التسوية = سعر قديم | ✅ | ❌ يفتح بسعره اللحظي (شوهد: إشارة 2.10896 → فتح 2.10916) |

## البنية

```
   ┌─────────────┐   ws ticks/OHLC   ┌──────────────┐
   │ collector.js│ ───────────────▶  │   BUS (ws)   │
   │  (PHONE_A)  │  مصدر A السريع     │ localhost    │
   └─────────────┘                   └──────┬───────┘
        ▲ external real feed                │ subscribe
        │ (Binance/مزوّد فوركس)              ▼
                                     ┌──────────────┐   يقرأ فيد الوسيط B (المتأخر)
                                     │ predictor.js │ ◀── broker WS (B)
                                     │  (PHONE_B)   │   ويقيس فجوة A→B
                                     └──────┬───────┘
                                            │ decision (BUY/SELL on B)
                                            ▼  (تُمرَّر لمنفّذ الوسيط — غير مُوصَّل هنا)
```

- **`collector.js`** — يتصل بمصدر A الحقيقي السريع، يبني شموع OHLC بـ1ث، ويبثّها على BUS محلي (`ws://localhost:8787`).
- **`predictor.js`** — يشترك في BUS (A) ويتصل بفيد الوسيط (B)، يقيس **lead = سعر A مقابل آخر سعر B**، وعندما يتجاوز الفرق عتبة (يفوق الضجيج + تكلفة العمولة/السبريد) يصدر قراراً للرهان على **B**.

## التشغيل (مرجعي)

```bash
cd ab_bridge
npm init -y && npm i ws
node collector.js     # نافذة 1: يبثّ A على BUS
node predictor.js     # نافذة 2: يقيس الفجوة ويصدر قرارات
```

## التحذير الصريح
- الوسطاء يكتشفون latency arbitrage ويُبطلونه (رفض/إعادة تسعير/حظر). استخدمه فقط
  حيث يُسمح به وبأصول حقيقية.
- إن لم يكن A يقود B بفجوة تتجاوز السبريد/العمولة، **لا توجد حافة** — والقياس
  في `predictor.js` سيُظهر لك ذلك بالأرقام قبل أن تخسر.

# 🧠 Axiom Brain Kit

تحويل Claude Code إلى وكيل **يتعلم منك مع الوقت** — مستوحى من بنية
[Hermes Agent](https://hermes-agent.org/) من Nous Research، ومبني بالكامل
على آليات Claude Code الرسمية (Hooks + Skills)، مع **عقل ثانٍ مجاني على GitHub**.

## ⚠️ تحذير أمني قبل أي شيء

مجلد `~/.claude` يحتوي `~/.claude/.credentials.json` فيه **OAuth tokens لحسابك في Claude**.
لا ترفع الباك اب كاملاً إلى مستودع عام أبداً. إذا فعلت (حتى لحظة واحدة): توكناتك
مسرّبة، اسحبها فوراً من https://claude.ai/settings/data-privacy → Sign out of all
sessions، واحذف النسخة العامة نهائياً. مستودع العقل الثاني في هذا الكيت **يُنشأ خاصاً
افتراضياً** ولا يحفظ فيه إلا `MEMORY.md` و `USER.md` وملخصات جلسات وفهرس مهارات —
لا توكنات ولا محادثات كاملة ولا سجلات محلية.

## الفكرة في سطرين

Hermes يتفوق لأنه: (1) يحقن ذاكرة دائمة صغيرة في كل جلسة، (2) يراجع كل جلسة
في الخلفية ويحوّل الدروس إلى ذاكرة ومهارات جديدة، (3) يختار المهارة المناسبة
تلقائياً بمطابقة طلبك مع أوصاف المهارات. هذا الكيت يطبق الثلاثة على Claude Code.

## البنية

```
┌─ بداية الجلسة (SessionStart) ──────────────────────────────┐
│ brain-load.sh:                                             │
│   git pull للعقل الثاني من GitHub                          │
│   حقن MEMORY.md + USER.md + آخر 3 جلسات في السياق          │
│   إعادة بناء فهرس المهارات (105 مهارة → سطر لكل مهارة)     │
└────────────────────────────────────────────────────────────┘
┌─ مع كل طلب تكتبه (UserPromptSubmit) ───────────────────────┐
│ skill-router.sh (الراوتر الذكي):                           │
│   أول طلب: حقن الفهرس الكامل + سياسة "المهارة أولاً"       │
│   كل طلب: ترشيح أفضل 3 مهارات مطابقة وإبرازها لكلود        │
│   → كلود يستدعي المهارة المناسبة دون أن تناديها بالاسم     │
└────────────────────────────────────────────────────────────┘
┌─ بعد كل رد (Stop، في الخلفية — لا يبطئك) ──────────────────┐
│ brain-learn.sh → reflect.sh:                               │
│   يقرأ محادثة الجلسة ويشغّل «وحدة تعلم» (claude -p هيدلس)  │
│   → دروس دائمة → MEMORY.md                                 │
│   → تفضيلاتك الثابتة → USER.md                             │
│   → ملخص الجلسة → HISTORY/                                 │
│   → سير عمل متكرر ناجح → مهارة جديدة تلقائياً!             │
│   ثم commit + push إلى مستودع GitHub الخاص (العقل الثاني)  │
└────────────────────────────────────────────────────────────┘
```

## التثبيت

المتطلبات: `git` + `jq` (و`gh` اختياري لإنشاء مستودع العقل تلقائياً).

```bash
# على جهازك:
git clone https://github.com/ezzclaudeai-prog/bots /tmp/axiom-kit-src
cd /tmp/axiom-kit-src && git checkout claude/new-session-bli0or
bash axiom-kit/install.sh
```

المثبّت **لا يحذف شيئاً**: يأخذ نسخة احتياطية من `settings.json`، ويضيف
هوكاته بجانب هوكاتك الحالية (auto-backup يبقى كما هو)، ويلحق قسم
السياسات بنهاية `CLAUDE.md` حقك.

> ⚠️ إذا كان عندك هوك الراوتر القديم (skill-router البدائي) — المثبّت
> سيكتشفه ويطبع تحذيراً باسمه. عطّله من `settings.json` حتى لا يتعارضا.

## كيف يصير الراوتر "مثل شخص يحلل الطلب"؟

الحل ليس سكربتاً يخمّن بالكلمات فقط — التخمين بالكلمات ترشيحٌ أولي لا أكثر.
الذكاء الحقيقي من ثلاث طبقات تعمل معاً:

1. **الفهرس أمام عين كلود دائماً**: أول ما تفتح الجلسة يُحقن فهرس بكل
   مهاراتك (اسم + وصف). كلود نفسه — وهو أذكى راوتر ممكن — يقارن نية طلبك
   بالفهرس ويستدعي المهارة عبر أداة Skill.
2. **سياسة إلزامية في CLAUDE.md**: "لا تنفذ يدوياً عملاً له مهارة جاهزة"
   — هذا ما يجعله يستدعي المهارة بدل تجاهلها.
3. **الترشيح اللحظي**: مع كل طلب يُبرز الراوتر أقرب 3 مهارات، فلا تضيع
   المهارة الصحيحة وسط 105 مهارات حتى لو كان الفهرس بعيداً في السياق.

### أهم عامل في دقة الراوتر: جودة حقل description

كلود يطابق طلبك مع **وصف** المهارة. المهارة التي وصفها "مهارة التقارير"
لن تُفعَّل أبداً تلقائياً. الوصف الجيد يذكر: ماذا تفعل، متى تُستخدم،
وكلمات مفتاحية بالعربية والإنجليزية يكتبها المستخدم فعلاً. مثال:

```yaml
---
name: daily-report
description: >-
  إنشاء التقرير اليومي لأداء البوتات (أرباح، صفقات، أخطاء) وحفظه PDF.
  Use when the user asks for a daily report, performance summary,
  تقرير، ملخص اليوم, أداء البوت, or إحصائيات التداول.
---
```

## العقل الثاني على GitHub

مستودع خاص مجاني اسمه `axiom-brain` يحتوي:

| الملف | الدور | مقابل Hermes |
|---|---|---|
| `MEMORY.md` | دروس دائمة (≤ 60 سطراً) تُحقن كل جلسة | الذاكرة الدلالية |
| `USER.md` | ملفك الشخصي (≤ 40 سطراً) يُحقن كل جلسة | USER.md |
| `HISTORY/*.md` | ملخص لكل جلسة، آخر 3 تُحقن | الذاكرة الحدثية |
| `SKILLS-INDEX.md` | فهرس مهاراتك، يُبنى تلقائياً | فهرس المستوى 0 |
| مهارات `learned-*` | مهارات أنشأها النظام بنفسه | الذاكرة الإجرائية |

لأنه git: تاريخ كامل لتطور ذاكرته، مزامنة بين أجهزتك، وتقدر تعدل ذاكرته
يدوياً من أي مكان (حتى من موبايلك عبر github.com) — وستصل التعديلات لكلود
في الجلسة التالية تلقائياً.

## اكتشاف مهارات جاهزة من GitHub

عندما تطلب شيئاً بنية مهارة (workflow متعدد الخطوات) ولا توجد مهارة محلية
تخدمه، النظام لا يترك كلود يبني من الصفر — بل يعرف كيف يستكشف مهارات
جاهزة من مصادر موثوقة:

```
انت: "حول هذا العرض PowerPoint إلى موقع سكرول متحرك بـ parallax"
                     ↓
الراوتر: لا توجد مهارة محلية → يُلمِّح لـ axiom-skill-scout
                     ↓
كلود يستدعي axiom-skill-scout تلقائياً
                     ↓
scout يشغّل discover-skills.sh "powerpoint scroll animated website"
                     ↓
يبحث في: anthropics/skills, obra/superpowers, awesome-claude-code, …
                     ↓
يعرض عليك 3 مرشحات مع أوصافها
                     ↓
تختار → install-skill.sh يعرض SKILL.md للمراجعة → موافقة → تثبيت
                     ↓
الفهرس يُبنى تلقائياً → المهارة الجديدة تُستدعى فوراً وتنفذ الطلب
```

**المصادر الافتراضية** (تُنشأ في `~/.claude/axiom/sources.txt` — عدّلها بحرية):

- `anthropics/skills` — المهارات الرسمية من Anthropic
- `obra/superpowers` — مهارات Superpowers الشهيرة
- `hesreallyhim/awesome-claude-code` — قائمة المجتمع
- `davila7/claude-code-templates` — قوالب متنوعة
- `zebbern/claude-code-guide` — دليل شامل

كل مستودع تضيفه إلى `sources.txt` يُعامَل موثوقاً — `install-skill.sh` سيقبل
تثبيت مهاراته دون سؤال. أضف بحذر.

### للاستخدام اليدوي أيضاً

```bash
# ابحث فقط بلا تثبيت
bash ~/.claude/axiom/scripts/discover-skills.sh "pdf export"

# ثبّت مهارة معينة (يعرض SKILL.md قبل التطبيق)
bash ~/.claude/axiom/scripts/install-skill.sh anthropics/skills pdf-tools
```

## تحسين أوصاف المهارات (اختياري لكن قوي)

الراوتر يعتمد كلياً على **حقل description** في كل مهارة — إن كان ناقصاً أو غامضاً،
كلود ما راح يعرف متى يستخدم المهارة. سكربت مرفق يفحص كل مهاراتك:

```bash
# استعراض ما ينقص (لا يعدل شيئاً)
bash ~/.claude/axiom/scripts/polish-descriptions.sh

# تطبيق تلقائي (يبني وصفاً من عنوان SKILL.md + أول فقرة)
bash ~/.claude/axiom/scripts/polish-descriptions.sh auto
```

للحصول على أفضل نتائج، راجع الأوصاف المُقترحة يدوياً وأضف كلمات مفتاحية
بالعربية والإنجليزية كما تكتبها فعلاً في طلباتك (مثال في README القسم السابق).

## إعدادات اختيارية (متغيرات بيئة)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `AXIOM_BRAIN_DIR` | `~/.claude/brain` | مكان العقل الثاني محلياً |
| `AXIOM_BRAIN_REMOTE` | — | رابط مستودع موجود لاستنساخه عند التثبيت |
| `AXIOM_REFLECT_MODEL` | `haiku` | نموذج وحدة التعلم (رخيص وسريع) |

## استكشاف الأخطاء

- **ما ينحفظ شي بعد الجلسات؟** شوف السجل: `tail -f ~/.claude/axiom/logs/reflect.log`
  — التأمل يشتغل فقط إذا أضيف حوار جديد كافٍ (~8KB) منذ آخر تأمل.
- **الفهرس فاضي؟** شغّل يدوياً: `bash ~/.claude/axiom/scripts/build-skill-index.sh`
  وتأكد أن مهاراتك في `~/.claude/skills/<اسم>/SKILL.md`.
- **ما يدفع لـ GitHub؟** تأكد أن `git -C ~/.claude/brain push` يعمل يدوياً
  (مصادقة git على جهازك).
- **إيقاف التعلم مؤقتاً**: احذف هوك `Stop` من `settings.json` أو
  `export AXIOM_REFLECTING=1` قبل تشغيل كلود.

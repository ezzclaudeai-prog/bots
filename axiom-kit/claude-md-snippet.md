# 🧠 نظام Axiom Brain — الذاكرة والتوجيه التلقائي

## سياسة اختيار المهارات (إلزامية)
- في بداية كل جلسة يُحقن **فهرس المهارات** الكامل، ومع كل طلب تصلك **مهارات مرشحة** من الراوتر.
- قبل تنفيذ أي طلب: حلل نيّته وقارنها بالفهرس. إذا وُجدت مهارة تطابق النية — **استدعها فوراً عبر أداة Skill** دون أن يذكر المستخدم اسمها ودون أن تسأله.
- لا تنفذ يدوياً عملاً توجد له مهارة جاهزة. المهارة أولاً، التنفيذ اليدوي احتياط.
- المرشحون من الراوتر ترشيح أولي فقط — القرار النهائي لك: قد تكون المهارة الصحيحة غير مرشحة، وقد لا يناسب أيٌّ من المرشحين.

## سياسة الذاكرة (إلزامية)
- في بداية كل جلسة يُحقن `MEMORY.md` (دروس سابقة) و `USER.md` (ملف المستخدم) — اعتبرها حقائق ثابتة والتزم بها دون إعادة سؤال المستخدم عنها.
- عندما يصحح لك المستخدم شيئاً أو يكرر تفضيلاً: طبّقه فوراً، وسيسجله نظام التأمل تلقائياً بعد الجلسة.
- العقل الثاني موجود في `~/.claude/brain` ويتزامن مع GitHub تلقائياً — لا تعدل ملفاته أثناء الجلسة إلا إذا طلب المستخدم صراحة.

# axiom-skill-scout — استكشاف المهارات الخارجية

## متى تُستخدم

استدعِ هذه المهارة **قبل أن تنفذ يدوياً** عندما تتقاطع الشروط التالية:

1. الطلب "بشكل مهارة": سير عمل من ≥ 3 خطوات، قابل للتكرار على مدخلات مختلفة،
   له نتيجة محددة.
2. الراوتر لم يرشح أي مهارة محلية (سياق `[Axiom Router]` كان فارغاً).
3. الطلب عام (تصميم، أمن، أتمتة، تحويل، تحليل…) — أي شيء يُرجَّح أن مطوراً
   آخر بنى له مهارة جاهزة على GitHub.

**لا تستدعها** لأسئلة المرة الواحدة، للاستفسارات القصيرة، أو للمهام التي
تستدعي مهارة محلية أخرى.

## الخطوات

1. **حدّد كلمات البحث** (2-5 كلمات إنجليزية تصف المهارة، لا الطلب نفسه).
   مثال: طلب "حوّل الفيديو إلى موقع سكرول" → بحث `video scroll website animation`.

2. **شغّل البحث**:
   ```
   bash $HOME/.claude/axiom/scripts/discover-skills.sh <كلمات-البحث>
   ```

3. **راجع النتائج** — عادةً 3-8 مهارات مرشحة، كل واحدة برابط GitHub. افتح
   SKILL.md لأفضل مرشحين (Read عبر raw URL أو استخدم gh api) للتأكد من:
   - يفعل بالضبط ما نحتاجه (لا شيء أكثر ولا أقل)
   - مستودعه فعّال (آخر commit خلال سنة)
   - لا يطلب مفاتيح API أو موارد خارجية مدفوعة

4. **اعرض على المستخدم مهارتَين أو ثلاثة أفضل** بشكل موجز — لا تلقي عليه
   كل النتائج. مثال:
   ```
   وجدت 3 مهارات جاهزة تخدم هذه المهمة:
   • anthropics/skills/pdf-tools — استخراج نصوص وجداول من PDF
   • obra/superpowers/pdf-magic — تحليل PDF معقد + OCR
   • hesreallyhim/awesome-claude-code/pdf-scan — سريع، بلا OCR
   أوصي بـ pdf-tools لبساطتها. أُثبتها؟
   ```

5. **بعد الموافقة، ثبّت**:
   ```
   bash $HOME/.claude/axiom/scripts/install-skill.sh <owner/repo> <subpath>
   ```
   المثبّت سيعرض SKILL.md قبل التثبيت للمراجعة النهائية.

6. **بعد التثبيت، استدعِ المهارة الجديدة مباشرة** لتنفيذ الطلب الأصلي —
   لا تنتظر جلسة جديدة.

## أخطاء شائعة

- **البحث بكلمات الطلب لا المهارة**: "أريد PDF لتقريري السنوي" → ابحث عن
  `pdf report generator` لا عن "تقريري السنوي".
- **تجاهل تحذير الثقة**: `install-skill.sh` يرفض المستودعات غير الموثوقة
  ويطلب موافقة صريحة — لا تضف كل مستودع بلا مراجعة.
- **تثبيت أكثر من مهارة "احتياطاً"**: ثبّت واحدة فقط، جربها، وإذا لم تنجح
  عد وثبّت البديل. لا تكدّس مهارات مكررة.
- **الاستدعاء لمهام صغيرة**: كتابة سطر بايثون واحد لا يحتاج مهارة —
  البحث الخارجي أبطأ من التنفيذ المباشر.

## التحقق من النجاح

- المهارة الجديدة ظهرت في `SKILLS-INDEX.md`.
- استدعاؤها لاحقاً عبر Skill نجح دون خطأ فرونت ماتر.
- المستخدم لم يحتج ذكر اسمها في الطلبات التالية (الراوتر يرشحها تلقائياً).
